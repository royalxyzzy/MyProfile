# Portfolio

### [Demo](https://cyberpunk-portfolio-five.vercel.app/)

A modern, responsive portfolio website built with Next.js 14, TypeScript, and Tailwind CSS. This project showcases a clean design with reusable UI components and optimized performance.

![1](/screenshots/1.png)
## 🚀 Features

- **Modern Stack**: Built with Next.js 14, TypeScript, and Tailwind CSS
- **Responsive Design**: Mobile-first approach with responsive layouts
- **Custom UI Components**: Reusable components including buttons, cards, inputs, and textareas
- **Optimized Performance**: Leverages Next.js optimization features
- **Type Safety**: Full TypeScript support for better development experience
- **Styling**: Utility-first CSS with Tailwind and custom global styles

## 🚦 Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine (version 18 or higher recommended).

### Installation

1. Clone the repository:
```bash
git clone https://github.com/cyrixninja/cyberpunk-portfolio.git
cd cyberpunk-portfolio
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Development

- Start editing by modifying [`app/page.tsx`](app/page.tsx) - the page auto-updates as you edit
- Add new components in the [`components/`](components/) directory
- Customize styles in [`app/globals.css`](app/globals.css) and [`app/main.css`](app/main.css)
- Utility functions go in [`lib/utils.ts`](lib/utils.ts)

## 📦 Available Components

This project includes several custom UI components:

- **[Button](components/button.tsx)** - Customizable button component
- **[Card](components/card.tsx)** - Flexible card container
- **[Input](components/input.tsx)** - Form input field
- **[Textarea](components/textarea.tsx)** - Multi-line text input

## 🎨 Styling

The project uses a combination of:
- **Tailwind CSS** for utility-first styling
- **Global CSS** in [`app/globals.css`](app/globals.css) for base styles
- **Component-specific styles** in [`app/main.css`](app/main.css)

## 📱 Responsive Design

The portfolio is built with a mobile-first approach and includes responsive breakpoints for:
- Mobile devices (< 768px)
- Tablets (768px - 1024px)
- Desktops (> 1024px)
